# Expense Tracker

A web-based **Expense Tracker application** that helps users record, organize, filter, and analyze their daily expenses through a simple and user-friendly interface.

## Features

* User registration and login
* Credential verification during login
* Add new expenses with:

  * Expense name
  * Amount
  * Category
  * Date
* View recorded expenses
* Delete expenses
* Filter expenses by category
* Calculate total expenses
* Dynamic pie chart for expense visualization
* Logout functionality

## Technologies Used

* **Java**
* **HTML5**
* **CSS3**
* **JavaScript**

## How to Run

### Prerequisites

No Node.js, npm, or additional server setup is required for the basic web interface.

### Steps

1. Clone the repository:

```bash
git clone https://github.com/SIRIPURAMRAMYA/Expense-Tracker.git
```

2. Open the project folder:

```bash
cd Expense-Tracker
```

3. Open `index.html` in a web browser.

4. Register an account and log in to access the Expense Tracker.

## Expense Analysis

The application provides a category-based view of recorded expenses.

Users can:

* Filter expenses by category
* View the total amount of displayed expenses
* Analyze spending through a dynamic pie chart
* Review recorded expenses

The expense summary and chart update according to the displayed expense data.
